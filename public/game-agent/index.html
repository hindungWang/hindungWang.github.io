Game Agent: Stray

这是什么

Stray 是我这段时间一直在做的微信游戏助手 Bot。它通过 Wechaty 桥接到微信，能在群里被 @stray 直接唤起：你问它什么游戏、想找折扣、看榜单，它都会调用后面的工具链拿到真实数据再组织成回复。

核心能力：

  • 自然语言对话 + 工具调用：消息进来走通用 Agent Loop —— LLM 判断意图，必要时调工具取数据，再整理成带 emoji 的回复；上下文超出预算自动摘要压缩、历史可以卸载，不会一问上下文就丢。
  • 游戏工具链：搜索、详情（评分 / 媒体评测 / 各平台价格 / 图 / 视频）、热榜与精选折扣、Steam / PS5 / NS / Epic 各平台折扣、在玩榜、高分榜。
  • 主动功能：每天 12:00 在活跃群里发一条话题暖场；愿望单降价监控（每 6 小时查一次，降价在群里提醒）；定期把群里的讨论提炼成结构化偏好事实。
  • 长期记忆：SQLite 存储；分层记忆 —— 群讨论沉淀成 wiki、用户偏好画像、偏好事实增量提取。
  • Slash 命令兜底：/game search ...、/gold、/lss、/find（AI 搜索）、/kfc 等 20+ 快捷命令，不依赖 LLM 也能用。

技术栈：TypeScript（ts-node）· Wechaty + wechaty-puppet-service · OpenAI 兼容 API（可切 DashScope 百炼）· SQLite · Jest。

在线试玩

直接在下面的窗口里用自然语言跟它对话——它收到的每条指令都会经过我的消息网关路由到 Agent，实时返回结果。
